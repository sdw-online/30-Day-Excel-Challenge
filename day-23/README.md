# Day 23 - Dynamic Array Functions

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=YykiAwglQFQ)

## What You'll Learn
- Using UNIQUE and SORTBY to generate dynamic sorted lists
- Generating sequences and random arrays with SEQUENCE and RANDARRAY
- Reshaping and combining data with TOROW, TOCOL, VSTACK, HSTACK, DROP, TAKE, and TEXTSPLIT
