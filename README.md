# 30 Day Excel Challenge

**30 days. 30 lessons. From zero to Excel confident.**

Master Excel from scratch with daily video lessons, hands-on datasets, and real-world exercises. Whether you're aiming for your first data role or levelling up your spreadsheet skills, this challenge gives you the structure and practice to get there.

📺 [Watch the series on YouTube](https://www.youtube.com/playlist?list=PL92LwdfbhlXG4E-u5i7ZnLq2HeQYLVnbM)

---

## What You'll Learn

### Week 1: Excel Fundamentals (Days 1-7)
Build your foundation - navigating Excel, formatting, formulas, sorting, filtering, charts, and conditional formatting.
> Interface, formatting, SUM/AVERAGE/MAX, sorting/filtering, column/bar/line/pie charts, conditional formatting, **Project 1**

### Week 2: Functions & Pivot Tables (Days 8-14)
Work with functions that transform and summarise your data, plus pivot tables for instant insights.
> IF/IFS/AND/OR, text functions, aggregate functions, pivot tables (2 parts), data validation, **Project 2**

### Week 3: Lookups & Data Cleaning (Days 15-21)
Connect data across sheets, clean messy datasets, and automate transformations with Power Query.
> Conditional formatting (advanced), VLOOKUP/HLOOKUP, INDEX+MATCH, XLOOKUP, data cleaning, Power Query, **Project 3**

### Week 4: Advanced Analytics & Automation (Days 22-30)
Build production-grade dashboards - dynamic arrays, Power Query (advanced), Power Pivot with DAX, data quality, macros, and a full capstone project.
> Data viz (advanced), dynamic arrays, Power Query (merges/appends), Power Pivot/DAX, data quality, macros/VBA, data-entry forms, keyboard shortcuts, **Capstone Project**

## Prerequisites

- A computer (Windows, Mac, or Linux)
- Microsoft Excel (2016 or later recommended; Microsoft 365 for dynamic array functions)

That's it. No coding experience needed.

---

## Setup Guide

### Step 1: Install Excel
If you don't have Excel, you can use:
- [Microsoft 365](https://www.microsoft.com/en-gb/microsoft-365) (subscription)
- [Excel for the web](https://www.office.com/launch/excel) (free with a Microsoft account - some features limited)

### Step 2: Clone This Repo
```bash
git clone https://github.com/sdw-online/30-Day-Excel-Challenge.git
```

Or download as ZIP: **Code -> Download ZIP** on this page.

### Step 3: Start Day 1
Go to the [`day-01/`](day-01/) folder, open the README, and follow along.

Each day has:
- Practice Excel workbooks
- Datasets used for each exercise
- A link to the video lesson
