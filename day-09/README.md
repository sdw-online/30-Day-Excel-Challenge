# Day 09 - Text Functions

**Video:** [Watch on YouTube](https://www.youtube.com/watch?v=ns1dbkGGt-k)

## What You'll Learn
- Cleaning and transforming text with UPPER, LOWER, PROPER, and TRIM
- Extracting characters with LEFT, RIGHT, MID, FIND, and LEN
- Combining text using CONCAT and TEXTJOIN

## Getting Started

2. Watch the video lesson
3. Follow along and complete the exercises
